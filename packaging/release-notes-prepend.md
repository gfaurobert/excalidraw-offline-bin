## Linux-only release

**This GitHub Release contains Linux x86_64 assets only.** Windows and macOS builds for **v0.7.0** were not end-to-end tested; the latest published **Windows/macOS** builds remain **[v0.5.0](https://github.com/gfaurobert/excalidraw-offline-bin/releases/tag/v0.5.0)** until a follow-up release.

## Highlights (since v0.6.0)

- **Excalidraw upgraded to 0.18.0-4ce38fb** — upstream changes including sticky notes (`N`) and right-click drag to pan
- **Fix: Reload (Ctrl+R) on a saved drawing with unsaved edits** — no longer wrongly says “This drawing has no file path yet”; now offers Save / Discard and reload / Cancel
- **Headless PNG export CLI output unchanged** — 14/14 PNGs pixel-identical to the previous version
