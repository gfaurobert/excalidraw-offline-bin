# Excalidraw Offline

Local desktop app for `.excalidraw` files — upstream Excalidraw in a thin **Tauri 2** wrapper (system webview on Linux, Windows, and macOS).

**Status:** end-to-end tested on Linux, Windows 11, and macOS (universal). The next GitHub release will ship Tauri builds; [Releases](https://github.com/gfaurobert/excalidraw-offline-bin/releases) still list older tags until then. Get current builds from CI artifacts or [build from source]({{ '/install.html' | relative_url }}) — see [What's new]({{ '/whats-new.html' | relative_url }}).
