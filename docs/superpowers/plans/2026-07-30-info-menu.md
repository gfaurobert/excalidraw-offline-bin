# Info Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a native Info menu (Runtime, Assets, About App, About Excalidraw) with zenity/kdialog dialogs; remove the footer; show transient status in the header.

**Architecture:** Desktop owns Info menu items and native info dialogs. Version strings are resolved at startup from `deno.json` and the installed `@excalidraw/excalidraw` package. The React footer is removed; existing `status` state renders in the header. Startup no longer enqueues the Ready dialog string as UI status.

**Tech Stack:** Deno Desktop menus, zenity/kdialog, existing HTTP poll/`status` commands, React header in `frontend/src/App.tsx`.

**Spec:** `docs/superpowers/specs/2026-07-30-info-menu-design.md`

## Global Constraints

- Native **Info** menu next to File (flat, four items)
- Each item opens a zenity/kdialog info dialog (no webview About modal)
- Menu ids: `info-runtime`, `info-assets`, `info-about-app`, `info-about-excalidraw`
- Runtime body: `Ready · dialog: {dialogBackend}+http`
- Assets body: `Images save into assets/ next to the .excalidraw file.`
- App version from root `deno.json`; Excalidraw version from installed package (`frontend/node_modules/@excalidraw/excalidraw/package.json`), fallback `"unknown"`
- Remove footer entirely; transient status in header
- Do not enqueue Ready dialog string as UI status on startup
- Do not rewrite header status to Ready on successful `/api/info`

```ts
export type InfoDialogResult =
  | { ok: true }
  | { ok: false; reason: "unavailable" | "error"; detail?: string };

export function buildInfoDialogArgs(
  backend: "zenity" | "kdialog",
  title: string,
  text: string,
): string[] {
  if (backend === "zenity") {
    return ["zenity", "--info", `--title=${title}`, `--text=${text}`];
  }
  return ["kdialog", "--title", title, "--msgbox", text];
}

export async function infoDialog(
  title: string,
  text: string,
): Promise<InfoDialogResult> {
  if (await commandExists("zenity")) {
    const result = await runDialog(buildInfoDialogArgs("zenity", title, text));
    if (result.ok) return { ok: true };
    if (result.reason === "cancelled") return { ok: true };
    return { ok: false, reason: result.reason, detail: result.detail };
  }
  if (await commandExists("kdialog")) {
    const result = await runDialog(
      buildInfoDialogArgs("kdialog", title, text),
    );
    if (result.ok) return { ok: true };
    if (result.reason === "cancelled") return { ok: true };
    return { ok: false, reason: result.reason, detail: result.detail };
  }
  return { ok: false, reason: "unavailable", detail: "no zenity/kdialog" };
}
```

Note: `runDialog` currently treats empty stdout + success as a path dialog cancel in some paths — verify zenity `--info` return handling. If `runDialog` mis-classifies info OK as cancelled, either:

- treat `cancelled` as success inside `infoDialog` (as above), or
- add a small `runInfoDialog(args)` that only checks exit code (prefer if `runDialog` path logic is wrong for `--info`).

Prefer exit-code-only runner if Step 4 manual/unit behavior is wrong:

```ts
async function runInfoCommand(args: string[]): Promise<InfoDialogResult> {
  try {
    const useSetsid = await commandExists("setsid");
    const cmd = new Deno.Command(useSetsid ? "setsid" : args[0]!, {
      args: useSetsid ? args : args.slice(1),
      stdout: "null",
      stderr: "piped",
    });
    const { success, code, stderr } = await cmd.output();
    if (success || code === 0) return { ok: true };
    const detail = new TextDecoder().decode(stderr).trim();
    return { ok: false, reason: "error", detail: detail || `exit ${code}` };
  } catch (err) {
    return { ok: false, reason: "error", detail: String(err) };
  }
}
```

Wire `infoDialog` to `runInfoCommand` + `buildInfoDialogArgs` if needed.

```ts
export async function readJsonVersion(filePath: string): Promise<string> {
  try {
    const raw = await Deno.readTextFile(filePath);
    const data = JSON.parse(raw) as { version?: unknown };
    if (typeof data.version === "string" && data.version.length > 0) {
      return data.version;
    }
    return "unknown";
  } catch {
    return "unknown";
  }
}

export function readAppVersion(denoJsonPath: string): Promise<string> {
  return readJsonVersion(denoJsonPath);
}

export function readExcalidrawVersion(packageJsonPath: string): Promise<string> {
  return readJsonVersion(packageJsonPath);
}
```
