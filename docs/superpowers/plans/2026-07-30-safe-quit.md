# Safe Quit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make File → Quit and window close save unsaved work (prompt for a path when needed) and abort quit on cancel or save failure.

**Architecture:** Replace the native quit menu role with a custom Quit item and intercept window `close` with `preventDefault`. Both enqueue `{ type: "quit" }` for the UI. The UI saves if dirty, then `POST /api/quit`, which sets an allow-close flag, closes the window, and `Deno.exit(0)`.

**Tech Stack:** Deno Desktop (`Deno.BrowserWindow`), local HTTP command queue, React UI in `frontend/src/App.tsx`.

**Spec:** `docs/superpowers/specs/2026-07-30-safe-quit-design.md`

## Global Constraints

- Cancel / save failure → abort quit; stay open
- Dirty + path → silent save then quit; dirty + no path → path prompt then save
- Clean → quit immediately
- No “Discard?” / “Don’t Save” on quit
- Same behavior for File → Quit and window close
- After `/api/quit`: `allowClose = true`, then `win.close()`, then `Deno.exit(0)`

```ts
/** Re-entrancy helper for Deno BrowserWindow "close" + safe quit. */
export function createCloseGuard() {
  let allowClose = false;
  return {
    shouldDeferClose(): boolean {
      return !allowClose;
    },
    grantClose(): void {
      allowClose = true;
    },
  };
}
```

```ts
  const runSave = useCallback(async (
    forcePicker: boolean,
    presetPath?: string,
  ): Promise<boolean> => {
    await apiLog(
      "info",
      `runSave start forcePicker=${forcePicker} busy=${busyRef.current} path=${pathRef.current} preset=${presetPath ?? ""}`,
    );
    if (busyRef.current) {
      await apiLog("info", "runSave skipped: busy");
      return false;
    }

    let path = presetPath?.trim() || pathRef.current;
    if (forcePicker || !path) {
      const suggested = path ?? `${homeRef.current}/drawing.excalidraw`;
      const entered = await askPath(
        "save",
        "Save Excalidraw file — enter full path:",
        suggested,
      );
      if (entered === null || entered === "") {
        setStatus("Save cancelled");
        await apiLog("info", "runSave cancelled at path dialog");
        return false;
      }
      path = ensureExt(entered);
      await apiLog("info", `runSave path chosen: ${path}`);
    }

    return await writeSceneToPath(path);
  }, [askPath, writeSceneToPath]);
```

- [ ] **Step 4: Add runQuit**

After `runSave` / near other runners, add a `quittingRef` next to the other refs (with `busyRef`):

```ts
  const quittingRef = useRef(false);
```

Then add:

```ts
  const runQuit = useCallback(async () => {
    await apiLog("info", `runQuit start dirty=${dirtyRef.current} busy=${busyRef.current}`);
    if (quittingRef.current || busyRef.current) {
      await apiLog("info", "runQuit skipped: busy or already quitting");
      return;
    }
    quittingRef.current = true;
    try {
      if (dirtyRef.current) {
        const saved = await runSave(false);
        if (!saved) {
          await apiLog("info", "runQuit aborted: save cancelled or failed");
          setStatus((prev) =>
            prev.startsWith("Save failed") || prev === "Save cancelled"
              ? prev
              : "Quit cancelled"
          );
          return;
        }
      }
      setStatus("Quitting…");
      await apiLog("info", "runQuit POST /api/quit");
      await apiJson("/api/quit", {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify({}),
      });
    } catch (err) {
      await apiLog("error", `runQuit failed: ${String(err)}`);
      setStatus(`Quit failed: ${String(err)}`);
    } finally {
      quittingRef.current = false;
    }
  }, [runSave]);
```

Note: after a successful `/api/quit` the process exits, so `finally` may not run — that is fine.
